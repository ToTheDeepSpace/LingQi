# 0.1.50：评分入口、消息导航与首批免费上架

用户于 2026-09-20 确认先发布本批，交易闭环继续开发；实时聊天、真实订单、分段收款和提现不在本批内，不得将原型接入生产当作真实交易。

## 活动规则

- 全平台前 100 位审核通过的委托师，每人 1 条，从首次审核通过起 365 天。
- 提交仅进入人工审核，不预占名额；最后一个名额由数据库事务锁分配，不能超发。
- 已知的已验证账号身份去重；人工审核仍需核验同一服务者，技术指纹不等于实名识别。
- 修改、下架、重新上架、重复审核均不重计时；名额不回收。到期停止公开展示，不自动收费。
- 历史付费 / 既有上架权益保留，不消耗本次免费名额；已付费用不自动退款。
- 名额用完时仍待审的申请须由用户主动付款，再由管理员审核，不能自动扣费。
- 评分按已审核的社区评分和评价人数排序；认证、付费、保证金与事件认定不进入评分加分。

1. 备份腾讯云当前生产库，核对库名和旧表行数；执行 `20260920120946_provider_listing_first_100_year.sql`。仅新增字段、空表和后台角色权限，不改写历史业务记录。
2. 部署后端和网站。`PROVIDER_LISTING_FREE_CAMPAIGN_ENABLED` 默认关闭；这不影响既有已获免费权益。旧小程序仍走既有上架付款流程。
3. 上传 0.1.50，完成微信审核并正式发布；核对线上版，不以开发版或体验版代替。
4. 在生产服务显式设置 `PROVIDER_LISTING_FREE_CAMPAIGN_ENABLED=1` 并重启，确认 `/api/lc/provider-listings/promotion` 返回 `available:true`、`days:365`。同步核对通知跳转为正式版。
5. 用户手机验收：新用户免付款提交、人工审核公开、下架重上、通知与分享、店家 / DM 评分入口；不要为测试向真实用户乱发通知或收费。
