## 本批实现

- `api/banxijianRules.ts`：服务价款20%预约、80%见面尾款；交通费单列并全额预存，合计字段仅包含服务价款与交通费，不包含尚未确定的平台费。
- 保证金可不缴，三档100／500／1000元；提供档位比较，不擅自发明综合排名公式或具体加分。
- 停止接单且没有未完成订单／未结售后，才能判定剩余可退余额符合退还条件。缺失或不合法的状态一律不能判为可退。
- 金额使用整数分并检查安全整数范围。若服务价格的20%出现不足一分的结果，返回`needs_rounding_policy`，不擅自四舍五入；这是待确认计算分支，尚未施加到用户界面。
- 这些是纯函数，不收款、不退钱、不建立可提现余额。未来接口必须从服务端核实身份和账目，并以事务、锁定和幂等控制防止重复退款；不能把纯函数输出当作转账授权。
