# 委托·伴戏间交互草稿

2026-09-11，剧幕录内嵌委托市场的本地交互原型。不是已上线的小程序，不具备真实交易能力。

## 体验

入口为找委托师。建议依次点击：林川 → 免费咨询 → 去预约 → 选9月19日并填示例地点 → 发送申请 → 卖家工作台确认 → 模拟预约付款 → 模拟见面付尾款 → 完成／售后。

“我的”里可查看订单、咨询、卖家工作台及保证金；列表支持城市、日期、预算和名字筛选。保留百科、红黑榜与需求／自主应征的示例入口。完整百科和红黑榜不是本原型的重建范围。

人物、照片、评价、订单、审核、余额均为明确标记的虚构示例。刷新后重置，不向线上发送任何业务请求。

验证记录见 `design-qa.md`。类型检查、构建、28个受保护运行时文件校验及4项静态包测试通过；主交互已在内置浏览器操作验证，但内容区域一比一截图的裁剪工具异常，完整设计验收暂未关单。

## 已表达的规则

- ¥1,000服务款＋单列¥300车马费：预约款¥500，见面后尾款¥800。
- 申请不付款；卖家确认后再走模拟预约付款。真实锁档、并发冲突和24小时超时仍待服务端实施，手动档期只是交互展示。
- 咨询不收费，聊天与订单分开；聊天仅本地回显，无真实推送。
- 修改委托条进入模拟审核状态，不替换公开价或历史订单快照。
- 自愿保证金100／500／1000元；服务中或有未结售后时禁用退还。退还按钮仅模拟条件结果，不代表结算、转账或到账承诺。
- 两个身份的订单分别处理；知月只演示自身订单确认，完整卖家编辑／档期／保证金工作台以林川为样例。
