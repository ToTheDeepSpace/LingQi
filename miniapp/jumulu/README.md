# 剧幕录小程序

基于 uni-app（Vue 3 + TypeScript）的微信小程序首版。生产 API 固定使用 `https://jumulu.jusichen.com/api`，管理后台继续使用网站 `/admin`。

## 当前 0.1.47 范围

- 首页、DM 档案、店家档案、角色点评、红黑榜、拼车区
- 微信登录、首次注册昵称、手机号绑定
- 档案认领、委托条上架和联系服务者使用微信小程序虚拟支付，支付结果由服务端回调或查单确认
- 登录前主动同意用户协议与隐私政策；小程序内可直接阅读条款，并由服务端校验协议版本
- DM/店家/角色评价、榜单投票与评论、全站 UGC 小旗帜举报；红黑榜信息流无需先进入详情即可举报
- 所有独立发布、评价、认领、反馈、账号修改表单统一登录前置；直接打开深链不会先暴露可填写表单或提前请求账号私有数据
- 举报入口会先确认登录；红黑榜主帖与评论统一使用受保护的举报控件，异常 URL 编码不会导致页面白屏
- 红黑榜发布，支持从 DM / 店家详情预填对象
- 首页、公开列表与公开详情支持从右上角发送给朋友和分享到朋友圈；发布、账号、举报等私密页面不开放分享
- DM / 店家待审档案创建
- 发布人主页和“我的内容”管理
- 本人认领档案、首次委托条上架、永久解锁同一委托师联系方式三项 `9 元`微信支付
- 付费前手机号验证与已有网站账号合并，服务资格统一归属主账号
- “我的”问题反馈，举报与反馈图片使用私密存储
- 微信文字内容安全同步检查：小程序业务写接口由服务端强制检查一次，客户端不再重复预检
- 微信图片内容安全异步检查：公开图片上传后进入微信检查，未通过前管理员不能审核公开
- 微信检查结果写入后台安全审计记录，保存 trace_id 与结果，不复制用户原文

当前小程序不代收真实委托价款，不做担保、分账或抽佣；网站管理后台和完整档案编辑继续使用网站端。

## 页面基线

- 所有页面使用同一条自定义导航栏；非首页显示返回按钮，直接打开子页时回退到对应上级或首页。
- 内容区不重复页面大标题，按“紧凑说明、单一工具区、真实内容”排列。
- 列表筛选与主要操作合并在同一工具区；表单使用无外层卡片结构和底部固定提交按钮。

```bash
npm install
npm run check
```
