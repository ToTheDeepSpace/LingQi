# 灵契攻略交易支付与礼物边界设计

日期：2026-06-23

## 背景

灵契要新增攻略交易页。攻略可以挂到剧本、角色、城市、店家、DM、车头、灵契师等对象上，用户购买后查看内容，创作者获得收入。

本设计只锁定交易、钱包、礼物和提现边界，不实现具体页面视觉。

## 核心原则

- 攻略交易主链路叫“购买攻略 / 解锁攻略”，不伪装成礼物或打赏。
- 礼物只能做看完后的自愿赞赏，不能作为解锁条件，不能暗示必须送礼。
- 用户侧“契约币”只做站内消费余额，不给普通用户提现。
- 创作者侧收入单独记为“创作者收入”，展示为待结算、可提现和已提现。
- 攻略收入进入冻结期，过了投诉、退款、违规处理窗口后才可提现。
- 第一版提现走申请 + 管理员审核 + 手工或半自动转账；自动分账、自动提现后置。
- 未成年人、异常消费、版权侵权、盗版和剧透必须有明确风控。

## 范围

第一版要做：

- 攻略列表和详情。
- 攻略发布。
- 剧透等级和版权承诺。
- 人工审核。
- 契约币购买攻略。
- 购买后查看正文。
- 创作者收入账本。
- 提现申请。
- 自愿礼物赞赏。
- 订单、流水、审计日志。
- 举报和暂停销售。

第一版不做：

- 自动分账。
- 用户之间转账。
- 普通用户提现契约币。
- 公开链上存证。
- 自动版权识别。
- 直播式礼物特效。

## 用户侧钱包

用户钱包继续使用契约币，但必须拆清楚余额来源：

- 充值币：用户实际充值获得。
- 赠币：注册、邀请、活动获得。

购买攻略时默认优先消耗赠币，再消耗充值币。前端必须提示：

- 契约币用于站内内容和互动消费。
- 契约币不是现金账户，不支持用户自行提现或转让。
- 充值前提示按需充值，充值后按规则消费。

## 创作者收入

创作者收入不是契约币余额，不能和用户钱包混在一起。

收入状态：

- `pending`：订单已支付，内容可看，收入待结算。
- `frozen`：冻结期内，等待投诉、退款、违规处理。
- `withdrawable`：可提现。
- `withdraw_requested`：已申请提现。
- `withdraw_paid`：已打款。
- `forfeited`：因侵权、欺诈、违规等被扣回或冻结。

默认冻结期建议 7 天。被举报、投诉、版权争议、退款争议时冻结期暂停，管理员处理后再流转。

## 礼物赞赏

礼物是附加功能，不是攻略交易主链路。

允许：

- 用户购买并阅读攻略后，自愿给作者送礼物。
- 礼物展示在攻略详情或作者主页里，作为支持记录。
- 礼物可计入创作者收入，但进入同样的冻结和提现流程。

禁止：

- 送礼后才可看攻略。
- 把攻略标成免费，但正文需要送礼才显示。
- 用礼物金额作为唯一排名、推荐或搜索排序依据。
- 打赏返现、自我打赏、诱导送礼。
- 给打赏用户设置特殊治理豁免或保护权限。

## 攻略商品

攻略字段：

- 标题。
- 摘要。
- 正文。
- 价格。
- 剧透等级：无剧透、轻剧透、重剧透、已玩后可见。
- 绑定对象：剧本、角色、城市、店家、DM、车头、灵契师或自定义对象。
- 内容类型：选本攻略、角色攻略、城市攻略、成车攻略、出片攻略、店家/DM经验、其他。
- 作者。
- 审核状态。
- 销售状态。
- 版权承诺。
- 退款和投诉规则。

禁止内容：

- 盗版剧本文本。
- 线索卡原文或照片。
- 谜底、核心机制完整复刻。
- 未授权素材包。
- 他人付费攻略搬运。
- 侵犯隐私、造谣、辱骂和违法内容。

允许内容：

- 选本建议。
- 非侵权体验总结。
- 妆造、道具、出片清单。
- 城市打本路线。
- 角色体验建议。
- 车头成车经验。
- 店家或 DM 运营经验。

## 购买流程

1. 用户打开攻略详情。
2. 未购买用户只看摘要、剧透等级、价格、作者、退款规则和版权提示。
3. 用户点击购买。
4. 后端检查登录、余额、内容状态、是否已购买。
5. 后端原子扣减契约币，创建订单和钱包流水。
6. 后端创建创作者收入记录，状态为冻结中。
7. 用户获得阅读权限。
8. 冻结期结束后，收入转为可提现。

幂等要求：

- 重复点击购买不能重复扣款。
- 已购买用户再次进入直接显示内容。
- 订单、钱包流水和收入流水必须能对账。

## 提现流程

第一版提现必须人工审核：

1. 创作者进入收入页。
2. 查看待结算、可提现、已提现。
3. 填写提现账号和实名信息。
4. 提交提现申请。
5. 管理员审核金额、账号、内容投诉、异常交易。
6. 管理员手工或半自动打款。
7. 管理员填写打款凭证和备注。
8. 系统将提现状态改为已打款。

提现前置条件：

- 完成手机号或邮箱验证。
- 完成创作者身份资料。
- 提现金额达到最低门槛，第一版建议 30 元。
- 近一段时间无严重违规或未处理投诉。

## 风控

消费风控：

- 首次购买或首次礼物赞赏展示规则。
- 单笔和单日高金额提示。
- 异常高频购买、短时间多账号送礼、自买自送礼进入风险队列。
- 未成年人账号不开放充值、礼物、创作者收益和提现。

内容风控：

- 攻略发布默认进入审核。
- 高剧透内容加强提示。
- 举报后可暂停销售。
- 管理员可以下架、退款、扣回未结算收入。

资金风控：

- 所有余额变化都写不可跳号流水。
- 钱包流水、订单、收入流水、提现流水分别留记录。
- 后台提供对账视图。
- 不允许删除流水，只能追加冲正或状态变更。

## 管理后台

管理员需要看到：

- 攻略审核队列。
- 攻略举报队列。
- 订单列表。
- 钱包流水。
- 创作者收入流水。
- 提现申请。
- 异常消费和异常礼物队列。
- 内容下架、退款、冲正和扣回操作日志。

所有管理员操作要写审计日志。

## 合规提示

前端必须在关键节点明确展示：

- 攻略是用户经验内容，不保证适合所有玩家。
- 内容可能含剧透，请按剧透等级谨慎购买。
- 禁止上传盗版、谜底、线索卡、未授权素材。
- 礼物赞赏是自愿支持，不是购买或解锁条件。
- 用户应理性消费，未成年人不得充值、购买礼物或参与创作者提现。

## 推荐实现顺序

第一阶段：

- 攻略表、订单表、购买记录、收入流水、提现申请表。
- 攻略发布、审核、购买、查看。
- 创作者收入页只读展示。

第二阶段：

- 提现申请和管理员处理。
- 礼物赞赏。
- 举报暂停销售。

第三阶段：

- 自动转账或支付机构分账。
- 更细的消费限额、异常识别和对账报表。

## 验收标准

- 未购买用户不能通过接口读到付费正文。
- 已购买用户刷新后仍可读正文。
- 重复购买不重复扣费。
- 用户钱包流水、订单和创作者收入可对账。
- 礼物不解锁任何内容。
- 未成年人账号无法充值、送礼、购买高风险内容或提现。
- 管理员可下架攻略并暂停销售。
- 举报后高风险攻略可临时隐藏或暂停销售。

## 自检

- 无待定字段：第一版字段、流程和边界已明确。
- 无监管伪装：礼物不能作为攻略解锁方式。
- 无提现混账：用户契约币和创作者收入分账本管理。
- 无直接资金池扩张：第一版提现人工审核，自动分账后置。
- 无范围漂移：不在本规格里做完整小程序、AI 解析或公开链存证。
